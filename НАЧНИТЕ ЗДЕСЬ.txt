EVENTGO — ГОТОВЫЙ САЙТ С БАЗОЙ ДАННЫХ

Основная база — PostgreSQL. Запасной режим — локальный SQLite.

Быстрый старт без установки (SQLite):
1. Полностью распакуйте папку, если получили её в архиве.
2. Дважды нажмите START.cmd (без файла db.env).
3. В браузере нажмите «Я организатор».

Основной вариант (PostgreSQL через Docker):
1. Установите Docker Desktop и выполните:
   docker compose -p eventgo up -d db
2. Скопируйте db.env.example в db.env.
3. Дважды нажмите START.cmd.
4. В окне запуска должна быть строка Database: PostgreSQL …

Или весь сайт в Docker:
   docker compose -p eventgo up --build -d
Откройте http://localhost:3000

Если браузер не открылся, введите адрес из окна запуска:
обычно http://127.0.0.1:3000

Не закрывайте окно запуска, пока работаете с сайтом.
Для остановки нажмите в нём Ctrl+C.

Подробная инструкция, аккаунты и режим локальной сети — в README.md.
