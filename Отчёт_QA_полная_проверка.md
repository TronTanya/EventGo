## Безопасность и граничные случаи

Все проверки пройдены:
- Без входа API отвечает 401, запросы без заголовка `X-EventGo` (защита от CSRF) — 403, у неизвестного API — 404.
- Введённый HTML (`<img src=x onerror=…>` в имени гостя) показывается как текст и не выполняется.
- При выгрузке в CSV формулы вида `=HYPERLINK(…)` экранируются.
- Из имени загружаемого файла вырезается путь `../`. Без входа файл не скачать. Участник команды не может удалить чужой файл.
- Приглашение одноразовое (при повторе — 410), короткий пароль не принимается.
- Смена пароля проверяет текущий пароль. После выхода сессия больше не действует.
- Ответы содержат заголовки `X-Content-Type-Options` и CSP/X-Frame-Options.

## Инцидент во время проверки

Первый прогон API-сценария по ошибке пошёл не на временную копию, а на рабочую базу `data/eventgo.sqlite`: переменная окружения с путём к копии не попала в процесс сервера. В рабочей базе появились тестовое мероприятие «QA Конференция 2026» (id 4) со всеми связанными записями и 4 сессии входа.

Как исправлено:
1. Перед очисткой состояние сохранено в `%TEMP%\eventgo_real_before_cleanup`.
2. Мероприятие 4 удалено каскадно, лишние сессии удалены.
3. Все таблицы сверены с копией, снятой до проверки: количество записей совпадает. Другие мероприятия не затрагивались.

Дальнейшие прогоны шли на копии, и это подтверждалось проверкой базы после каждого запуска.
