# EventGo

Готовый локальный веб-сервис для подготовки и проведения мероприятий. Интерфейс на русском языке, данные хранятся в SQLite. В комплекте есть демонстрационная база и среда запуска для Windows x64. Интернет, установка пакетов и отдельный сервер базы данных для запуска не нужны.

## Запуск на Windows

1. Если вы получили архив, **полностью распакуйте его**. Не запускайте сайт прямо из окна архива.
2. Откройте папку `yba` и дважды нажмите **START.cmd**.
3. Откроется браузер. Если этого не произошло, откройте адрес из окна запуска: обычно **http://127.0.0.1:3000**.
4. Нажмите **«Я организатор»** для демонстрации или введите данные аккаунта.
5. Не закрывайте окно запуска, пока работаете. Для остановки нажмите в нём **Ctrl+C**.

Поддерживается Windows 10/11 x64. При занятом порте 3000 приложение автоматически попробует следующий порт. Запускайте одну копию приложения за раз. Браузер должен поддерживать современные JavaScript-модули: актуальные Edge, Chrome или Firefox.

## Аккаунты для демонстрации

| Роль | Почта | Пароль |
| --- | --- | --- |
| Организатор | organizer@eventgo.local | EventGo2026! |
| Участник команды | team@eventgo.local | TeamGo2026! |
| Второй организатор | partner@eventgo.local | PartnerGo2026! |

Это локальные аккаунты. Письма на эти адреса не отправляются. Организатор управляет событиями, командой, гостями и бюджетом; при создании или в параметрах события можно выбрать или передать ответственного другому организатору. Член команды видит доступные ему события, меняет статус своих задач, пишет комментарии и загружает файлы. Бюджет, суммы расходов, стоимость подрядчиков и аналитика ему недоступны: финансовые данные также исключены из ответов сервера. Чтобы дать участнику доступ к новому событию, добавьте в команду контакт с его почтой и отправьте приглашение в кабинет.

Сменить пароль можно через аватар справа вверху → «Изменить пароль». После этого входите через обычную форму: кнопка демонстрации использует исходный пароль.

## Гостевой режим

На странице входа нажмите **«Я гость — афиша мероприятий»** или откройте `/afisha` по адресу вашего сайта. Пароль не нужен. Гость видит текущие и предстоящие события, может зарегистрироваться и показать электронный билет с QR-кодом. Рабочие разделы команды гостю недоступны.

В разделе **«Мои билеты»** (`/my-tickets`) сохраняются билеты, полученные в этом браузере. На другом устройстве можно добавить билет по коду `EG:…` или сохранённой ссылке. Откройте **«Показать билет»**, чтобы предъявить QR на экране телефона. При очистке данных браузера сохранённый список билетов исчезнет, поэтому сохраняйте ссылки для переноса. Автоматическая отправка билетов по почте не подключена.

## Большие файлы

Максимальный размер одного файла — **4 ГБ**, то есть **4 294 967 296 байт**. Загрузка и скачивание выполняются потоково, без помещения целого файла в оперативную память. При загрузке показывается прогресс; не закрывайте окно сайта или сервера до завершения. Нужно достаточно свободного места на диске. Пустые, оборванные и превышающие лимит загрузки не сохраняются как файлы мероприятия. Видео загружаются как обычные файлы и доступны для скачивания.

## Чат команды

Откройте мероприятие и выберите **«Чат команды»** в меню слева. Организатор и участники команды могут переписываться внутри этого мероприятия. Гости и пользователи без доступа к событию не могут читать или отправлять сообщения.

Введите сообщение и нажмите **«Отправить»** или Enter. Shift+Enter добавляет новую строку. История сохраняется в базе и остаётся после перезапуска сайта. Новые сообщения подгружаются автоматически; старые доступны по кнопке **«Загрузить предыдущие сообщения»**. Если вы читаете историю, появится кнопка перехода к новым сообщениям. Максимальная длина — 4000 символов.

Для общения с разных компьютеров все участники должны открыть **одну и ту же запущенную копию сайта** по сетевому адресу компьютера-сервера из инструкции ниже. Отдельные скопированные папки yba используют отдельные базы и не обмениваются сообщениями между собой.

## Что работает

- Создание, редактирование и удаление мероприятий: название, тип, дата и время, место или онлайн-ссылка, описание, цель, число мест, бюджет, статус и ответственный организатор.
- Список задач и канбан-доска, ответственные, сроки, приоритеты, статусы, просроченные задачи, комментарии и вложения.
- Чат команды для каждого мероприятия с сохранением истории и автоматическим обновлением.
- Команда и подрядчики: роли, контакты, услуги, стоимость, статус работы и прогресс по задачам.
- Каталог площадок и подрядчиков (только для организаторов): поиск по городу, вместимости и стоимости, сравнение до трёх вариантов, кнопка «В событие» выбирает площадку или добавляет подрядчика и сразу ставит плановый расход в бюджет.
- Бюджет: статьи расходов, план и факт, остаток, уведомление о перерасходе, выгрузка CSV.
- Гостевая страница регистрации по отдельной ссылке. Контроль числа мест, запрет повторной регистрации с одной почтой, согласие на использование данных для регистрации.
- Информирование гостей (раздел «Рассылки»): объявления организатора на странице билета, письмо с билетом при регистрации, рассылка объявлений и приглашений в опрос. Почта работает в демо-режиме: письма не отправляются, а сохраняются в журнале с предпросмотром.
- Индивидуальные билеты с настоящим QR-кодом. Проверка билета по коду или ссылке, отметка входа, отклонение повторных и отменённых билетов. Сканирование камерой доступно в браузерах с BarcodeDetector и разрешением на камеру; ввод кода работает без камеры.
- Список гостей, изменение статусов, поиск и выгрузка CSV для Excel.
- Загрузка, скачивание и удаление файлов до 4 ГБ. Файлы можно связать с задачей.
- Календарь событий и сроков задач выбранного мероприятия.
- Сводная аналитика (вкладка «Все мероприятия» в разделе «Аналитика», только для организаторов): регистрации против плана, посещаемость, расходы и бюджет, задачи и оценки гостей по всем вашим событиям, выгрузка в CSV.
- Ожидаемое число гостей — отдельное поле события рядом с вместимостью: план по гостям виден на обзоре, в «Участниках» и в аналитике.
- Дашборд, аналитика, JSON-отчёт, лента действий. Автообновление каждые 20 секунд, когда окно активно и форма не открыта.
- Сохранение изменений после обновления страницы и перезапуска сервера.
- Адаптивный интерфейс для телефона и компьютера.

Демонстрация содержит три события, задачи, вымышленные контакты с адресами example.com, расходы и два текстовых файла. Время событий указано по Якутску (UTC+9).

## Показать полный сценарий

1. Войдите организатором и откройте «Мероприятия» → «Создать событие».
2. Добавьте участника команды и задачу, назначьте ответственного.
3. Добавьте статью бюджета и фактические затраты.
4. Откройте «Участники» → «Регистрация» → «Открыть страницу».
5. Заполните форму гостя, получите билет, скопируйте код `EG:…`.
6. Вернитесь к организатору → «Проверить билет» → вставьте код → отметьте вход.
7. Посмотрите изменения в аналитике и обновите страницу: данные сохранятся.

## Перенос и резервное копирование

Остановите сервер с помощью Ctrl+C и скопируйте **всю папку yba**. Отправьте её другому человеку: он открывает START.cmd. Абсолютных путей к компьютеру разработчика в приложении нет.

Главная база — `data/eventgo.sqlite`. Загруженные файлы — `data/uploads/`. При работающем сервере рядом могут находиться файлы `eventgo.sqlite-wal` и `eventgo.sqlite-shm`: не удаляйте их вручную. Чтобы получить согласованную копию папки, сначала остановите сервер. Сохраняйте резервную копию перед заменой данных.

Организатор может скачать согласованную копию SQLite через меню аккаунта → «Скачать копию базы». В эту выгрузку **не входят загруженные файлы**: для полного резервного копирования сохраняйте папку целиком. База содержит все мероприятия и учётные записи этой установки. Для восстановления остановите сервер и замените `data/eventgo.sqlite` сохранённой копией, а `data/uploads/` — соответствующей копией файлов. Не восстанавливайте базу из недоверенного источника.

Для чистой демонстрационной базы остановите сервер, переименуйте `data` в `data-old` и снова запустите приложение. Будет создан новый набор демонстрационных данных. Старые данные останутся в `data-old`.

## Другие устройства в локальной сети

По умолчанию сайт доступен только на компьютере, на котором запущен. Это позволяет передавать папку без настройки сети.

Для совместной демонстрации в доверенной локальной сети можно открыть PowerShell в папке yba и выполнить:

```powershell
$env:HOST = '0.0.0.0'
.\runtime\node.exe --no-warnings .\server.mjs
```

На другом устройстве откройте `http://IP-КОМПЬЮТЕРА:3000`. При необходимости разрешите входящие подключения в брандмауэре Windows для частной сети. В ссылках регистрации используйте этот же адрес вместо 127.0.0.1. В режиме HTTP по локальной сети камера или буфер обмена могут быть недоступны; ввод кода билета работает.

Перед использованием в сети смените демонстрационные пароли. Эта сборка предназначена для локальной работы и хакатона. Для публикации в интернете нужны HTTPS, конфигурация хостинга, резервное копирование и адаптация к требованиям конкретного организатора. Оплата, рассылка писем и внешние календари не подключены. ИИ подключается через собственный ключ DeepSeek или OpenAI. Новые аккаунты через интерфейс не создаются; предусмотрены два локальных аккаунта, гостевой вход без пароля и упрощённые роли.

## Технологии и файлы проекта

Использованы Node.js 24, стандартный HTTP-сервер, встроенный модуль node:sqlite, HTML, CSS и JavaScript. Внешних npm-зависимостей нет. Цвета и композиция интерфейса основаны на приложенном брендбуке EventGo; шрифты Manrope и Inter включены в папку и загружаются локально. В презентации предлагались Django и PostgreSQL; в переносимой версии выбран Node.js и SQLite, чтобы запускать сайт без установки PostgreSQL и Python.

| Файл / папка | Назначение |
| --- | --- |
| START.cmd | Запуск Windows с открытием браузера |
| TEST.cmd | Проверка основных сценариев в отдельной временной базе |
| runtime/node.exe | Включённая среда Node.js для Windows x64 |
| runtime/LICENSE.txt | Лицензии Node.js и включённых компонентов |
| server.mjs | HTTP-сервер, API, права доступа, файлы и резервная копия |
| file-storage.mjs | Потоковая загрузка и скачивание файлов до 4 ГБ |
| db.mjs | Схема SQLite и демонстрационные данные |
| public/ | Интерфейс, стили, иконки и генерация QR |
| data/ | База SQLite и файлы пользователей |
| tests/ | Интеграционные проверки |

На Linux/macOS установите Node.js 24 LTS и выполните `sh start.sh`. Включённый node.exe предназначен для Windows x64. Установка npm-пакетов не требуется.

Дополнительные настройки: `PORT` — фиксированный порт, `HOST` — сетевой адрес, `EVENTGO_DATA_DIR` — другая папка данных. Без этих настроек используются переносимые значения по умолчанию.

Проверки можно запустить через TEST.cmd или `runtime\node.exe --no-warnings --test tests\*.test.mjs`. Они создают отдельную временную базу и не меняют данные проекта.

## Проверка больших файлов

Обычная проверка через TEST.cmd не создаёт файл на 4 ГБ. Для полного испытания откройте PowerShell в папке yba и выполните:

```powershell
$env:EVENTGO_TEST_LARGE_UPLOAD = '1'
.\runtime\node.exe --no-warnings --test tests/*.test.mjs
```

Эта проверка использует отдельную временную базу, передаёт ровно 4 ГБ, скачивает файл потоком, сравнивает SHA-256 и удаляет временные данные. На диске нужно не менее 5 ГБ свободного места.

## ИИ-ассистент

Откройте мероприятие → **«ИИ-ассистент»**. Диалог с моделью доступен организатору и участникам команды, хранится отдельно для каждого пользователя и сохраняется после перезапуска.

Для подключения организатор нажимает **«Подключить ИИ»** или кнопку настроек, выбирает DeepSeek или OpenAI, вводит ключ соответствующего сервиса и сохраняет. По умолчанию для DeepSeek используется **deepseek-flash**, для OpenAI — **gpt-4.1-mini**. Можно указать другую модель, совместимую с API выбранного сервиса и доступную вашему аккаунту. Ключ не нужно отправлять в чат с разработчиком.

После сохранения ключа можно задавать вопросы. Нужны интернет и доступный лимит аккаунта выбранного ИИ-сервиса. Подписка на этот локальный сайт не включает внешний ИИ-сервис. Если ключ не настроен, сайт честно показывает настройку подключения и не выдаёт заготовленные ответы за ответы ИИ.

Вопрос и несколько последних сообщений личного диалога передаются выбранному ИИ-сервису. Переключатель **«Добавить сведения о мероприятии»** дополнительно передаёт описание, задачи и для организатора сводку бюджета. Участнику финансовые данные не передаются. Контактные поля, списки гостей, содержимое файлов и чат команды автоматически не отправляются. Ассистент консультирует и не меняет данные сайта. Внешний поиск не подключён.

Ключ хранится **вне папки yba**, в локальных настройках компьютера: на Windows — в LocalAppData/EventGo/ai. В архив сайта и копию SQLite ключ не входит. На другом компьютере организатор вводит собственный ключ повторно. Для серверного запуска также поддерживаются переменные OPENAI_API_KEY и OPENAI_MODEL. Для тестов каталог секретов можно переопределить через EVENTGO_SECRET_DIR.

В разделе ассистента можно загрузить предыдущие сообщения и очистить только свой диалог. Для одного пользователя по одному мероприятию обрабатывается один вопрос за раз. Повторное получение уже сохранённого ответа не создаёт дубликат.

Для OpenAI подключение использует POST https://api.openai.com/v1/responses с store:false. DeepSeek использует свой официальный API Chat Completions. Это не означает, что все журналы провайдера отключены: правила хранения данных определяет выбранный ИИ-сервис. Реальный ответ DeepSeek проверен через интерфейс сайта. Автоматические проверки используют имитацию внешнего API и отдельные временные базы.

Личная история ИИ входит в резервные копии локальной базы. Владелец компьютера и администратор установки могут читать эту базу. Ключ ИИ-сервиса в SQLite не записывается.

## DeepSeek

Ассистент поддерживает DeepSeek и OpenAI. В настройках выберите сервис, введите его ключ и модель. Для DeepSeek используется deepseek-flash и официальный адрес api.deepseek.com; формат Chat Completions. Поддерживаются переменные DEEPSEEK_API_KEY, DEEPSEEK_MODEL и EVENTGO_AI_PROVIDER.

Если системная папка локальных настроек недоступна, настройки могут храниться в Documents/Codex/.eventgo-ai, отдельно от yba. При наличии двух файлов применяется последний сохранённый. Ключ не записывается в SQLite и не входит в архив сайта. При переносе на другой компьютер нужен собственный ключ.
